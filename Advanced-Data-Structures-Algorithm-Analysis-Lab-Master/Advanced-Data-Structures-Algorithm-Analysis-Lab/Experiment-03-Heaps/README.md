# Experiment 3: Implementation of Heaps Using Python

## Aim
To implement Max Heap and Min Heap operations using Python.

## Language
Python 3

## Files
- `heaps.py` — source code for heap operations
- `input.txt` — sample initial integers
- `sample_output.txt` — example output
- `output.txt` — final heap contents saved when the program exits

## Operations
- Build Max Heap and Min Heap from initial values
- Insert an element into either heap
- Delete the maximum from Max Heap
- Delete the minimum from Min Heap
- Display both heaps
- Display the elements in ascending order using heap sort concept
- Save final heaps to `output.txt`

## How to Run
1. Install Python 3.
2. Keep `heaps.py` and `input.txt` in the same folder.
3. Run from a terminal:
   ```bash
   python heaps.py
   ```
4. Select operations from the menu. Choose `0` to exit and save the final heaps.

## Result
Max Heap and Min Heap operations were implemented successfully using Python's `heapq` module.
